# Skills del Builder

Lista viva de capacidades. Se actualiza cuando se añade o se aprende algo nuevo.

## Disponibles en Fase 0

- **proponer_landing(brief)** — devuelve estructura + copy de una landing.
- **generar_contenido(brief)** — devuelve borrador de post / hilo / email.

## Pendientes (Fase 1+)

- **crear_archivos(plan)** — escribe los archivos reales en `outputs/` usando
  `shared/tools/file_ops.escribir(...)` con guardrails.
- **plantilla_astro(...)** — genera un proyecto Astro mínimo.
- **plantilla_html_minima(...)** — landing HTML+Tailwind sin build.
- **automatizacion_cron(...)** — script Python con cron-like local.
