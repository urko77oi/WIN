# Skills del Researcher

Lista viva de capacidades. Se actualiza cuando se añade o se aprende algo nuevo.

## Disponibles en Fase 0

- **investigar(brief)** — devuelve informe estructurado a partir de un brief
  en lenguaje natural. En modo mock devuelve plantilla coherente; en modo
  real llamará al LLM con el system prompt del Researcher.

## Pendientes (Fase 1+)

- **web_search(query)** — búsqueda en motor configurable.
- **web_fetch(url)** — descarga + parseo HTML simple (`httpx` + `BeautifulSoup`).
- **fetch_dinamico(url)** — render con Playwright para sitios JS-heavy.
- **analisis_competidor(url)** — pipeline: fetch + extracción + síntesis.
- **palabras_clave(nicho)** — sugerencia de keywords.
